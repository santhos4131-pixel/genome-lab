What does GC content mean?

GC content is the percentage of bases in a DNA sequence that are either guanine (G) or cytosine (C).

GC content = ((G + C) ÷ sequence length) × 100

Example: if a sequence has 3 G bases, 3 C bases and 10 bases total, GC content = 60%.

AI / ML limitations

Important points to include in your project discussion.

  • A model learns patterns from its training examples; it does not understand biology like a domain expert.
  • Four training sequences are far too few to represent real biological diversity.
  • Features such as base counts and GC content discard sequence order and other biological context.
  • A prediction for an unlabelled sequence cannot be confirmed without a known reference label or further analysis.
  • Performance should be evaluated on separate, representative test data.

Glossary

Nucleotide

A building block of DNA. This project uses A, T, G and C.

Feature

A measurable property extracted from data for analysis or machine learning.

Classifier

A model that assigns an input to one of the learned categories.

GC content

The percentage of sequence bases that are G or C.

Training data

Examples used by a machine-learning model to learn patterns.

FASTA

A common text format for storing biological sequences with headers.
