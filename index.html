04 / LEARNING NOTES

Understand the workflow

What this mini-project demonstrates and where the method has limits.

⌗
Feature extraction

Convert biological sequence characters into numerical values that a machine-learning algorithm can process.

◈
Model training

Use labelled examples so a classifier can learn patterns associated with Group A and Group B.

⌁
Prediction

Apply the learned decision rules to the feature values of an unknown DNA sequence.

Which features may be useful?

Nucleotide counts and GC content describe the base composition. The tiny dataset makes it difficult to know which features generalize.

Can the prediction be verified?

Not from this assignment dataset alone. The unknown sequence has no supplied true label, so its predicted group cannot be confirmed.

What if a sequence is very different?

The classifier may make an unreliable prediction because it has seen only a few examples and may not have learned broader biological patterns.

One genomics application

Researchers can use ML to help identify genetic patterns associated with diseases, alongside appropriate biological validation.

Important limitation: This project uses only four short sequences and basic composition features. Real genomic analysis needs much larger, diverse, carefully labelled datasets and biological validation. A sequence's biological meaning is not determined by GC content alone.
